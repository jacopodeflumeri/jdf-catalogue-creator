>
> **Optional and niche.** Only adopt if this app has **admin-editable config**

- **Yes** → proceed; you'll need to identify exactly which tables count as "config."

### Step 0 — Branch, prerequisites, assess

1. Create a git branch (e.g. `retrofit/data-sync`). All work goes here.
2. Read, in the template: `docs/template/capabilities/DATA_SYNC.md` (overview plus the

   `docs/template/capabilities/_registry.json`, and the **2026-05-14** entry in `MIGRATION.md`.
3. **Note the prerequisites** and check what you can:
   - The shared `mapp-labs-data-sync` bucket must exist with SSM exports
     `/mapp-labs/shared/data-sync/bucket-name` and `/mapp-labs/shared/data-sync/bucket-arn`
     in this AWS account (provisioned via the `mapp-labs-shared` template). **If those
     SSM params are absent, `cdk synth` will fail at deploy** — flag this as a DevOps

4. In **this** app, look at the Prisma schema to understand which tables are config vs
