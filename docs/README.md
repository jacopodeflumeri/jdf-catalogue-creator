# Docs

| Folder | What lives there | Who edits it |
|---|---|---|
| `docs/` (this level) | **This app's own docs** — features, decisions, pitfalls | You and your agent, in the same commit as the code |
| [`docs/template/`](template/README.md) | Reference shipped by `labs-app-template`: how auth, deploy, capabilities and the design system work | Nobody, except when applying a template retrofit — changes come from the template |
| [`docs/retrofit/`](retrofit/README.md) | Prompts for catching up with newer template versions | Comes from the template |

## Writing app docs

Keep one living doc per feature area here (e.g. `docs/ORDERS.md`): what it does,
how it works, key files, data model, decisions (with dates and the why), and
pitfalls. Update it when behaviour changes, link it below, and never put secrets
in it. See "Documenting your work" in [`AGENTS.md`](../AGENTS.md).
